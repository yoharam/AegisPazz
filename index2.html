📚 ¿Qué son los Intervalos?

Un intervalo es un conjunto de números reales que se encuentran entre dos valores dados, llamados extremos del intervalo.

Símbolos Importantes:

  • ( ) Paréntesis = El extremo NO está incluido
  • [ ] Corchetes = El extremo SÍ está incluido
  • ● Punto cerrado = Incluido en la recta numérica
  • ○ Punto abierto = NO incluido en la recta numérica

📊 Tipos de Intervalos

Notación Tipo Desigualdad Descripción Representación
(a,b) Abierto a < x < b Extremos NO incluidos ○————○
[a,b] Cerrado a ≤ x ≤ b Extremos SÍ incluidos ●————●
(a,b] Semiabierto izq. a < x ≤ b Izquierda NO, derecha SÍ ○————●
[a,b) Semiabierto der. a ≤ x < b Izquierda SÍ, derecha NO ●————○
(-∞,a) Infinito izq. abierto x < a Menores que a ←——○
(-∞,a] Infinito izq. cerrado x ≤ a Menores o iguales a a ←——●
(a,+∞) Infinito der. abierto x > a Mayores que a ○——→
[a,+∞) Infinito der. cerrado x ≥ a Mayores o iguales a a ●——→

💡 Ejemplos Paso a Paso

Ejemplo 1: (2,5)

Paso 1: Identificar tipo
Los paréntesis ( ) indican que es un intervalo abierto
Paso 2: Escribir desigualdad
2 < x < 5
Paso 3: Representar en recta
○————————○
 2        5
Descripción: Todos los números reales mayores que 2 y menores que 5

Ejemplo 2: [0,3)

Paso 1: Identificar tipo
Corchete [ y paréntesis ) = intervalo semiabierto por la derecha
Paso 2: Escribir desigualdad
0 ≤ x < 3
Paso 3: Representar en recta
●————————○
 0        3
Descripción: Todos los números reales desde 0 (incluido) hasta 3 (no incluido)

✏️ Ejercicios de Tu Lista

4. Números mayores o iguales a 1 y menores que 7:

Respuesta: [1,7)

Explicación: "Mayores o iguales" = corchete [, "menores que" = paréntesis )

5. [3,6] - Tipo de intervalo:

Respuesta: Intervalo cerrado

Explicación: Ambos extremos tienen corchetes, por lo tanto están incluidos

7. Números mayores que -3 y menores que 5:

Respuesta: (-3,5)

Explicación: "Mayores que" y "menores que" (sin igualdad) = paréntesis en ambos

8. Entre 0 y 4, incluyendo 4 pero no 0:

Respuesta: (0,4]

Explicación: 0 no incluido = paréntesis (, 4 incluido = corchete ]

13. Números menores o iguales a -5:

Respuesta: (-∞,-5]

Explicación: Desde infinito negativo hasta -5 (incluido)

💡 Consejos para Resolver:
1. Lee cuidadosamente las palabras clave: "mayor que", "menor o igual", etc.
2. "Mayor/menor QUE" = paréntesis ( )
3. "Mayor/menor o IGUAL QUE" = corchetes [ ]
4. Infinito (∞) siempre usa paréntesis
5. En la recta: ● = incluido, ○ = no incluido
